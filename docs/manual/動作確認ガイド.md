# novelaid-cli 動作確認ガイド

本書は、小説執筆補助CLIツール（`novelaid-cli`）をユーザーおよび開発者として手動で動作確認するための手順書です。

---

## 1. 現在の実装状況（Step 3-5 / v0.4.0 時点）

現在、開発計画の **Step 3-5（AI対話による原稿ファイル書き換え実証：ルビ自動設定機能）** まで完了しています。

* **確認できること**:
  - Node.js 環境上での CLI の起動
  - **Pi Coding Agent SDK 公式フルTUI（`InteractiveMode`）** の起動（シンタックスハイライト、Markdown描画、セッションツリー等）
  - **SDK標準拡張（InlineExtension）** による、ローカル LM Studio モデルの自動検出とプロバイダー動的登録
  - SDK標準の全コマンド（`/model` 対話型セレクター、`/login`、`/tree`、`/export` 等）の利用
  - novelaid-cli 独自拡張スラッシュコマンド（`/novelaid-info`, `/cd`, `/pwd`, `/ls`, `/dir`, `/ruby`）の利用
  - **二層スコープ（プロジェクトルート固定＆作業フォルダー相対移動）** とルート上限ガードによる安全性
  - **フォルダー・ファイル種別の自動判別（`NovelaidDocumentType`）** とAIコンテキスト（`before_agent_start`）への動的ペルソナ注入
  - **セマンティックジャンプ（`/cd novel`, `/cd plot`, `/cd wiki`, `/cd root`）** とTab補完
  - **ルビ自動設定支援（`/ruby [ファイル名]`）**:
    - `novelaid-ruby` 構文（`|親文字《ルビ》`）に準拠したルビ自動設定
    - 対象原稿の自動検出（カレントフォルダーおよび小説フォルダー内）
    - 初出優先・二重ルビ防止・既存ルビ保護
    - AIの `read` ➔ 推論 ➔ `edit`（差分プレビュー）➔ ファイル書き換え ➔ 永続化
  - サンプルプロジェクト（`test-novel/`）による執筆・編集支援の即時体験
* **まだできないこと（今後の拡張予定）**:
  - 誤字脱字チェック・文体校正・表記揺れ統一への横展開
  - キャラクター・世界観設定の整合性チェック専用ツール

## 2. ユーザーとしての動作確認手順

ユーザー（CLIの利用者）の視点で、ツールをビルドして対話セッションを実行する手順です。

### 前提条件
- **Node.js**: v20.0.0 以上（推奨: v22 / v24）
- **npm**: v10.0.0 以上
- **LM Studio**:
  - LM Studio を起動し、「Developer」タブ等でローカル推論サーバー（ポート `1234`）を開始しておきます。
  - お好みのモデル（例: `qwen` や `gemma` など）をロードしておきます。

### 手順 1: 依存関係のインストール
プロジェクトのルートフォルダーで以下のコマンドを実行します。

```powershell
npm install
```

### 手順 2: プログラムのビルド
TypeScriptコードをJavaScriptにコンパイルします。

```powershell
npm run build
```

### 手順 3: フルTUI対話セッションの開始（通常起動）

```powershell
npm start
```
またはグローバルコマンド（`npm link` 実施後）：
```powershell
novelaid
```

Pi SDK 公式のフル TUI 画面が起動します。
起動時にローカルの LM Studio 稼働状況を自動検知し、`lm-studio` プロバイダーとして動的に登録されます。

#### 主な操作・コマンド
- 入力欄で文字を入力し、EnterでAIへ送信（リッチなMarkdown・ストリーミング描画）
- `/pwd`: 現在の作業フォルダーの位置（相対パス・絶対パス・書庫ルート）および**フォルダー種別（`novel`, `markdown` 等）**を表示
- `/cd [パス | novel | plot | wiki | root]`: 作業フォルダーを移動。相対パス（`/cd 10_novels`, `/cd ..`）だけでなく、**セマンティックジャンプ（`/cd novel [サブパス]`, `/cd plot`, `/cd wiki`, `/cd root`）**にも対応。**`/cd ` 入力時にセマンティック候補およびサブフォルダー候補が自動ポップアップし、Tabキーで補完可能**です。
- `/ls [パス]` / `/dir [パス]`: 現在の作業フォルダー（または指定フォルダー）内のファイル・フォルダー一覧を表示（フォルダー優先、ファイルサイズ表示、隠しファイル除外、**ドキュメントタイプ `[novel]`, `[markdown]` 等の自動判別表示**）。引数のフォルダー名もTab補完に対応しています。
- `/ruby [ファイル名]`: **ルビ自動設定支援コマンド**。原稿ファイル内の難読漢字や固有名詞へのルビ振りを案内します。ファイル名を省略した場合はカレントフォルダーまたは小説フォルダー内の原稿ファイルを自動検出します。
- **AIへの現在地・文脈自動連携**: `/cd` でフォルダーを移動すると、AIエージェントに現在の作業フォルダーとドキュメントタイプが自動注入され、小説本文執筆モードや設定考案モードなど、場所に応じた最適なペルソナで応答します。
- `/model`: 登録されているモデル（LM Studio のモデルおよび設定済みクラウドモデル）を対話型リストから選択・切り替え
- `/novelaid-info`: novelaid-cli の接続状況・プラグイン情報・現在の作業フォルダーとドキュメントタイプを表示
- `/help`: Pi SDK が提供する全コマンド一覧を表示
- `Ctrl+C` または `/exit`: セッションを終了

### ルビ自動設定支援（AI原稿ファイル書き換え）の動作確認

同梱のサンプル作品 `test-novel` を使って、AIが原稿を読み込み・差分編集・ファイル更新する一連の流れを確認できます。

1. **プロジェクト指定で起動**:
   ```powershell
   npm start -- -p test-novel
   ```
2. **小説フォルダーへ移動**:
   ```text
   /cd novel
   ```
   ※ `10_novels` へジャンプし、ドキュメントタイプが `novel` に切り替わります。
3. **ルビ案内コマンドを実行**:
   ```text
   /ruby
   ```
   ※ `第1話_旅立ちの朝.txt` が自動検出され、対話指示のプロンプト例が表示されます。
4. **AIに対話でルビ振りを指示**:
   ```text
   第1話_旅立ちの朝.txt の難読漢字と固有名詞にルビを振って
   ```
5. **Diff確認とファイル適用**:
   - AIが `read` ツールで原稿を読み込み、初出の難読語（「躊躇」「隘路」「刹那」「翡翠」等）を抽出。
   - `|親文字《ルビ》` の構文で `edit` ツールの差分プレビューが表示されます。
   - 変更内容を目視確認して承認すると、ファイルが永続化されます。

## 3. その他の実行モード

### 軽量 readline モード（`--simple`）
従来のシンプルなターミナル1問1答モードで対話を行いたい場合に使用します。

```powershell
npm start -- --simple
# または
novelaid --simple
```

対話ループ内では `/help`, `/model`, `/clear`, `/exit` などのコマンドが利用可能です。

### 推論テストモード（`--test`）
対話ループに入らず、1往復の疎通テストのみを行いたい場合は `--test` を指定します。

```powershell
npm start -- --test
# または
novelaid --test
```

### 利用可能なモデルの一覧表示（`--list-models`）
Pi SDK標準のCLIフラグもそのまま利用できます。登録された LM Studio モデルが一覧表示されることを確認できます。

```powershell
npm start -- --list-models
```

### プロジェクトフォルダーの指定（`-p` / `--project` / パス指定）
通常はCLIを実行したカレントディレクトリを作業対象としますが、開発中のデバッグや別フォルダーの作品を扱いたい場合に、起動引数で対象プロジェクトフォルダーを指定できます。

```powershell
# オプション指定
novelaid -p ../novel-draft
novelaid --project "D:\novels\my-novel"

# 位置引数での指定
novelaid ../novel-draft

# テストモードとの併用
novelaid --test -p ../novel-draft
```
※指定されたフォルダーが存在しない、またはディレクトリでない場合は安全にエラーメッセージが表示されて終了します。

## 4. 開発者向け手動動作確認手順

### 1. 型チェック
```powershell
npx tsc --noEmit
```

### 2. 開発用即時実行
```powershell
npm run dev
```

### 3. ビルドと成果物実行
```powershell
npm run build
node dist/cli.js
```

### 4. 単体テスト・E2Eテストの実行
各種機能の自動テストスクリプトを実行して検証できます。
```powershell
# ルビモジュール単体テスト
node scratch/test-ruby-module.mjs

# 原稿書き換え・ルビ適用E2E実証テスト
node scratch/test-ruby-rewrite-e2e.mjs

# セマンティック /cd 移動テスト
node scratch/test-semantic-cd.mjs

# コンテキスト動的注入テスト
node scratch/test-workspace-prompt.mjs
```
