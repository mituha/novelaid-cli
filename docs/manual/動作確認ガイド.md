# novelaid-cli 動作確認ガイド

本書は、小説執筆補助CLIツール（`novelaid-cli`）をユーザーおよび開発者として手動で動作確認するための手順書です。

---

## 2. ユーザーとしての動作確認手順

ユーザー（CLIの利用者）の視点で、ツールをビルドして対話セッションを実行する手順です。

### 前提条件
- **Node.js**: v20.0.0 以上（推奨: v22 / v24）
- **npm**: v10.0.0 以上
- **LM Studio**:
  - LM Studio を起動し、「Developer」タブ等でローカル推論サーバー（ポート `1234`）を開始しておきます。
  - お好みのモデル（例: `qwen` や `gemma` など）をロードしておきます。

### 手順 1: 依存関係のインストール
プロジェクトのルートフォルダーで以下のコマンドを実行します。

```powershell
npm install
```

### 手順 2: プログラムのビルド
TypeScriptコードをJavaScriptにコンパイルします。

```powershell
npm run build
```

### 手順 3: フルTUI対話セッションの開始（通常起動）

```powershell
npm start
```
またはグローバルコマンド（`npm link` 実施後）：
```powershell
novelaid
```

Pi SDK 公式のフル TUI 画面が起動します。
起動時にローカルの LM Studio 稼働状況を自動検知し、`lm-studio` プロバイダーとして動的に登録されます。

#### 主な操作・コマンド
- 入力欄で文字を入力し、EnterでAIへ送信（リッチなMarkdown・ストリーミング描画）
- `/pwd`: 現在の作業フォルダーの位置（相対パス・絶対パス・書庫ルート）を表示
- `/cd [パス]`: 作業フォルダーを移動（例: `/cd 10_novels`, `/cd ..`, 引数なしでルート復帰。ルート上限保護付き）。**`/cd ` 入力時にサブフォルダー候補が自動ポップアップし、Tabキーで補完可能**です。
- `/ls [パス]` / `/dir [パス]`: 現在の作業フォルダー（または指定フォルダー）内のファイル・フォルダー一覧を表示（フォルダー優先、ファイルサイズ表示、隠しファイル除外、**ドキュメントタイプ `[novel]`, `[markdown]` 等の自動判別表示**）。引数のフォルダー名もTab補完に対応しています。
- `/model`: 登録されているモデル（LM Studio のモデルおよび設定済みクラウドモデル）を対話型リストから選択・切り替え
- `/novelaid-info`: novelaid-cli の接続状況・プラグイン情報・現在の作業フォルダーを表示
- `/help`: Pi SDK が提供する全コマンド一覧を表示
- `Ctrl+C` または `/exit`: セッションを終了

## 3. その他の実行モード

### 軽量 readline モード（`--simple`）
従来のシンプルなターミナル1問1答モードで対話を行いたい場合に使用します。

```powershell
npm start -- --simple
# または
novelaid --simple
```

対話ループ内では `/help`, `/model`, `/clear`, `/exit` などのコマンドが利用可能です。

### 推論テストモード（`--test`）
対話ループに入らず、1往復の疎通テストのみを行いたい場合は `--test` を指定します。

```powershell
npm start -- --test
# または
novelaid --test
```

### 利用可能なモデルの一覧表示（`--list-models`）
Pi SDK標準のCLIフラグもそのまま利用できます。登録された LM Studio モデルが一覧表示されることを確認できます。

```powershell
npm start -- --list-models
```

### プロジェクトフォルダーの指定（`-p` / `--project` / パス指定）
通常はCLIを実行したカレントディレクトリを作業対象としますが、開発中のデバッグや別フォルダーの作品を扱いたい場合に、起動引数で対象プロジェクトフォルダーを指定できます。

```powershell
# オプション指定
novelaid -p ../novel-draft
novelaid --project "D:\novels\my-novel"

# 位置引数での指定
novelaid ../novel-draft

# テストモードとの併用
novelaid --test -p ../novel-draft
```
※指定されたフォルダーが存在しない、またはディレクトリでない場合は安全にエラーメッセージが表示されて終了します。
