# novelaid-cli 動作確認ガイド

本書は、小説執筆補助CLIツール（`novelaid-cli`）をユーザーおよび開発者として手動で動作確認するための手順書です。

---

## 1. 現在の実装状況（Step 2-1 時点）

現在、開発計画の **Step 2-1（Pi SDK ModelRuntime によるモデル接続・一覧取得と疎通テスト）** まで完了しています。

* **確認できること**:
  - Node.js 環境上での CLI の起動
  - **Pi Coding Agent SDK** の `ModelRuntime` を介した AI プロバイダー（LM Studio）の動的登録
  - ローカルで稼働している LM Studio（`http://localhost:1234/v1`）からのモデル一覧の取得とターミナル表示
  - `--test` オプションによる、LM Studioモデルへの実際の1往復推論テスト（プロンプト送信と応答受信）
  - LM Studio 未起動時のエラーハンドリングとトラブルシューティング案内
* **まだできないこと（Step 2-2 以降で実装予定）**:
  - 連続的な対話ループ（チャットUI）
  - ストリーミングリアルタイム描画（文字が順次流れてくる表示）
  - 小説執筆に特化したプロンプトや設定資料の自動読み込み

## 2. ユーザーとしての動作確認手順

ユーザー（CLIの利用者）の視点で、ツールをビルドして起動確認を行う手順です。

### 前提条件
- **Node.js**: v20.0.0 以上（推奨: v22 / v24）
- **npm**: v10.0.0 以上
- **LM Studio**（任意ですが、ローカルAI接続を試す場合に推奨）:
  - LM Studio を起動し、「Developer」タブ等でローカル推論サーバー（ポート `1234`）を開始しておきます。
  - 何らかのモデル（例: `qwen2.5` 等）がロードされていると推論テストまで確認できます。

### 手順 1: 依存関係のインストール
プロジェクトのルートフォルダーで以下のコマンドを実行します。

```powershell
npm install
```

### 手順 2: プログラムのビルド
TypeScriptコードをJavaScriptにコンパイルします。

```powershell
npm run build
```

### 手順 3: CLIの実行

#### 方法 A: 通常起動（接続状態とモデル一覧の確認）
```powershell
npm start
```

**期待される出力例（LM Studio 起動時）**:
```text
=========================================
  novelaid-cli (小説執筆補助エージェント)  
=========================================
Pi Coding Agent SDK ランタイムを初期化中...

【AIモデル接続ステータス】
✔ ローカルLM Studio: 接続成功 (http://localhost:1234/v1)
  利用可能なモデル数: 9 件
   - [qwen/qwen3-4b-2507] qwen/qwen3-4b-2507 (コンテキスト窓: 128,000 tokens)
   - [qwen/qwen3-8b] qwen/qwen3-8b (コンテキスト窓: 128,000 tokens)
   ...

[Step 2-1] Pi SDK ModelRuntime によるモデル接続・一覧取得テストが完了しました。
```

*(※ LM Studioが未起動の場合は、警告と起動案内が表示されます)*

#### 方法 B: 推論疎通テスト（実際にAIモデルと1往復会話する）
`--test` オプションを渡すことで、検出されたモデルに対して実際にテストプロンプトを送信し、モデルからの応答を検証できます。

```powershell
npm start -- --test
```

**期待される出力例**:
```text
【推論疎通テスト（1往復）を実行中...】
テスト対象モデル: qwen/qwen3-4b-2507
モデル応答: "こんにちは！接続テストは正常に完了しました。ご質問やお手伝いが必要な場合は、いつでもどうぞ。"
✔ 推論疎通テストに成功しました！
```

#### 方法 C: グローバルコマンドとして実行
```powershell
# 初回のみリンク登録
npm link

# 通常起動
novelaid

# 推論テスト
novelaid --test
```

## 3. 開発者としての手動動作確認手順

開発者がコードを変更しながらテストを行う際の手順です。

### 1. TypeScriptの型チェック
```powershell
npx tsc --noEmit
```
*(エラーが何も表示されずに終了すれば合格です)*

### 2. 開発用即時実行（ビルド不要）
`tsx` を用いて、TypeScriptコード（`src/cli.ts`）を直接実行します。

```powershell
# 通常起動
npm run dev

# 推論テスト
npm run dev -- --test
```

### 3. 本番ビルドと成果物の確認
```powershell
npm run build
node dist/cli.js --test
```
