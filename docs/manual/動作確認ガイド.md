# novelaid-cli 動作確認ガイド

本書は、小説執筆補助CLIツール（`novelaid-cli`）をユーザーおよび開発者として手動で動作確認するための手順書です。

---

## 1. 現在の実装状況（Step 2-2 時点）

現在、開発計画の **Step 2-2（Pi SDKセッション連携とCLI対話UIの実装）** まで完了しています。

* **確認できること**:
  - Node.js 環境上での CLI の起動
  - **Pi Coding Agent SDK** の `ModelRuntime` を介したローカル AI（LM Studio）のモデル自動検出
  - **Pi Coding Agent SDK** の `AgentSession` を活用した対話セッションの確立
  - ターミナル上での双方向対話（作家プロンプト入力 ⇄ AIリアルタイムストリーミング応答）
  - セッション内コマンド（`/help`, `/model`, `/clear`, `/exit`）の実行
  - `--test` オプションによる、1往復の自動疎通テスト
* **まだできないこと（Step 3 以降で実装予定）**:
  - 小説執筆補助に特化したシステムプロンプト（キャラクター設定やプロット相談など）の自動注入
  - ワークスペース内の設定資料（Markdownファイル等）の自動読み込み

## 2. ユーザーとしての動作確認手順

ユーザー（CLIの利用者）の視点で、ツールをビルドして対話セッションを実行する手順です。

### 前提条件
- **Node.js**: v20.0.0 以上（推奨: v22 / v24）
- **npm**: v10.0.0 以上
- **LM Studio**:
  - LM Studio を起動し、「Developer」タブ等でローカル推論サーバー（ポート `1234`）を開始しておきます。
  - お好みのモデル（例: `qwen` や `gemma` など）をロードしておきます。

### 手順 1: 依存関係のインストール
プロジェクトのルートフォルダーで以下のコマンドを実行します。

```powershell
npm install
```

### 手順 2: プログラムのビルド
TypeScriptコードをJavaScriptにコンパイルします。

```powershell
npm run build
```

### 手順 3: 対話セッションの開始（通常起動）

```powershell
npm start
```

**対話画面の出力例**:
```text
=========================================
  novelaid-cli (小説執筆補助エージェント)  
=========================================
Pi Coding Agent SDK ランタイムを初期化中...

【AIモデル接続ステータス】
✔ ローカルLM Studio: 接続成功 (http://localhost:1234/v1)
  利用可能なモデル数: 9 件
   - [qwen/qwen3-4b-2507] qwen/qwen3-4b-2507 (コンテキスト窓: 128,000 tokens)
   ...

対話セッションを開始します（モデル: qwen/qwen3-4b-2507）
コマンド: /help (ヘルプ), /model (モデル情報), /clear (画面消去), /exit (終了)

作家> こんにちは！短編小説のアイデアを1つ教えて
AI> こんにちは！例えばこんなプロットはいかがでしょうか。
「古書店の奥に置かれた一冊のノート。そこには、誰かが『捨てた夢』が物語の形で記録されていた……」

作家> /model
現在のモデル: qwen/qwen3-4b-2507 (qwen/qwen3-4b-2507)
コンテキスト窓: 128,000 tokens

作家> /exit
対話セッションを終了します。執筆お疲れ様でした！
```

### 利用可能なコマンド
対話ループのプロンプト（`作家> `）にて、以下のスラッシュコマンドが利用できます。

| コマンド | 説明 |
|---|---|
| `/help` | 利用可能なコマンド一覧を表示します。 |
| `/model` | 現在の対話セッションで使用しているモデル名とコンテキスト窓サイズを表示します。 |
| `/clear` | ターミナル画面をクリアします。 |
| `/exit` または `/quit` | セッションを安全に破棄し、CLIを終了します。 |

## 3. その他の実行方法

### 推論テストモード（`--test`）
対話ループに入らず、1往復の接続テストのみを行いたい場合は `--test` を指定します。

```powershell
npm start -- --test
```

### グローバルコマンド（`novelaid`）としての実行
```powershell
# 初回のみリンク登録
npm link

# 通常起動（対話モード）
novelaid

# テスト実行
novelaid --test
```
