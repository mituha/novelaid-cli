# novelaid-cli 動作確認ガイド

本書は、小説執筆補助CLIツール（`novelaid-cli`）をユーザーおよび開発者として手動で動作確認するための手順書です。

---

## 1. 現在の実装状況（Step 1 時点）

現在、開発計画の **Step 1（プロジェクト基盤のセットアップ）** まで完了しています。

* **確認できること**:
  - Node.js 環境上での CLI の起動
  - コアエンジンである **Pi Coding Agent SDK** のモジュールロードと初期化関数の疎通
* **まだできないこと（Step 2 以降で実装予定）**:
  - AIとのインタラクティブな対話入力
  - LM Studio / Gemini へのプロンプト送信とストリーミング応答

## 2. ユーザーとしての動作確認手順

ユーザー（CLIの利用者）の視点で、ツールをビルドして起動確認を行う手順です。

### 前提条件
- **Node.js**: v20.0.0 以上（推奨: v22 / v24）
- **npm**: v10.0.0 以上

### 手順 1: 依存関係のインストール
プロジェクトのルートフォルダーで以下のコマンドを実行します。

```powershell
npm install
```

### 手順 2: プログラムのビルド
TypeScriptコードをJavaScriptにコンパイルします。

```powershell
npm run build
```

### 手順 3: CLIの実行

以下のいずれかの方法で実行できます。

#### 方法 A: npm スクリプトから実行（最も簡単）
```powershell
npm start
```

#### 方法 B: CLIコマンド（`novelaid`）として実行（実運用に近い形）
ローカルパッケージをグローバルリンクすることで、任意の場所から `novelaid` コマンドとして呼び出せます。

```powershell
# 初回のみリンクを登録
npm link

# コマンドとして実行
novelaid
```

### 期待される出力結果
正常に動作すると、ターミナルに以下のようなバナーと疎通確認メッセージが表示されます。

```text
=========================================
  novelaid-cli (小説執筆補助エージェント)  
=========================================
Pi Coding Agent SDK を読み込み中...

✔ Pi Coding Agent SDK の初期化関数を確認しました。

[Step 1] プロジェクト基盤のセットアップが正常に完了しました。
```

## 3. 開発者としての手動動作確認手順

コードの変更や型チェックを検証しながら手動テストを行う手順です。

### 1. TypeScriptの型チェック
コンパイルエラーや未解決の型定義がないかを検証します。

```powershell
npx tsc --noEmit
```
*(エラーが何も表示されずに終了すれば合格です)*

### 2. 開発用即時実行（ビルド不要）
`tsx` を用いて、TypeScriptコード（`src/cli.ts`）を直接実行します。ソースコードを修正した直後の素早い確認に最適です。

```powershell
npm run dev
# または
npx tsx src/cli.ts
```

### 3. 本番ビルドと成果物の確認
TypeScriptコンパイラによるトランスパイルを行い、`dist/cli.js` が生成されて実行できるかを確認します。

```powershell
npm run build
node dist/cli.js
```
