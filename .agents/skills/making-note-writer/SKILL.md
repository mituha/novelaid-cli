# メイキング記事執筆スキル（Making Note Writer）

このスキルは、`making/logs/YYYY-MM-DD.md` に記録されたプロンプト・作業手順と、`docs/dev/` の開発仕様をもとに、外部ブログ（note等）へそのまま投稿できる読み物記事を `making/notes/` に作成・更新するための手順書です。

## 1. 執筆スタイル・トーン＆マナー

* **文体**: 親しみやすく丁寧な「です・ます」調。
* **ターゲット読者**: AIを活用した創作（小説執筆）や、AIエージェント（Antigravity）による自動化環境構築に興味がある読者。
* **記事の魅力を高めるポイント**:
  1. **実際のプロンプトを見せる**: 「どんなプロンプトを投げたらAIがどう動いたか」を `making/logs/` から引用して具体的に紹介します。
  2. **試行錯誤や設計の意図を語る**: なぜそのフォルダ構成や仕組みにしたのか（例：なぜ小説コンテキストとメイキングを分離するのか等）をわかりやすく解説します。
  3. **視覚的なわかりやすさ**: フォルダ構成のツリーやMermaid図、箇条書きを適度に使い、長文でも読み疲れしないレイアウトにします。
     - **Mermaid構文の注意**: ノード名や矢印ラベル（`-->|"ラベル"|`）に空白、ピリオド、括弧等の記号が含まれる場合は、構文エラーを防ぐため必ずダブルクォーテーション（`""`）で囲みます。
  4. **リンクは相対パスを徹底**: 記事内外のファイルリンクには `file://` やローカル絶対パスを一切使わず、必ず相対パス（例: `../../docs/dev/〇〇.md`、外部プロジェクトは `../<project-name>/...`）を使用します。


## 2. 実行手順

1. **素材の収集**
   - 当日の作業ログ（`making/logs/YYYY-MM-DD.md`）の最新セクションを確認します（未抽出のプロンプトがある場合は `pwsh -c "./.agents/scripts/sync-prompt-log.ps1"` を実行して同期します）。
   - 関連する開発仕様書（`docs/dev/` 配下）を確認します。
2. **対象記事ファイルの決定**
   - `making/notes/index.md` を確認し、今回の作業が既存記事への追記（ブラッシュアップ）か、新しい連番記事（`02_〇〇.md` など）の作成かを判断します。
   - 新規作成時は [article-template.md](./resources/article-template.md) の構成を参考にします。
3. **記事の執筆・更新**
   - 導入 → 入力したプロンプトと背景 → 構築した仕組み・結果 → まとめ・次回予告 の流れで執筆します。
4. **目次（`making/notes/index.md`）の更新**
   - 新規記事を追加した場合やタイトル・概要が変わった場合は、必ず `making/notes/index.md` を最新状態に更新します。
