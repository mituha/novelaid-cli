# logs（作業・プロンプト記録）

このフォルダーには、日々の作業手順およびユーザーが入力したプロンプト原文を日次ファイル（`YYYY-MM-DD.md`）として時系列で記録します。

## 記録の仕組み（ハイブリッド方式）

1. **プロンプト原文・質疑応答の自動抽出（Hookスクリプト）**
   - `.agents/hooks.json` に設定された Lifecycle Hook（`PreInvocation` / `Stop`）により、`.agents/scripts/sync-prompt-log.ps1` が自動実行されます。
   - 会話トランスクリプト（`transcript_full.jsonl`）からユーザー入力プロンプト（`<USER_REQUEST>`）と選択式質問の回答を抽出し、改変・要約なしで当日のログファイルへ追記します。
2. **作業手順・変更点の解説追記（AIルール）**
   - 各タスクの完了時、AIエージェントがプロンプトセクションの直下に「実施した作業・手順」「作成・変更ファイル」「設計判断の理由」を追記します。
