# notes（投稿用メイキング記事）

このフォルダーには、本プロジェクト（AIによる自動小説執筆システム構築）の過程をまとめた、note等のブログ投稿用記事を格納します。

## 運用ルール

* **自動作成・更新**: 環境構築やシステム改善の各ステップが完了するごとに、`.agents/skills/making-note-writer` スキルに基づき、`making/logs/` の作業ログと `making/dev/` の開発仕様から記事を自動で作成・更新します。
* **文体・トーン**: 親しみやすい「です・ます」調で、実際に入力したプロンプトや試行錯誤の過程を読者が追体験できる読み物形式とします。
* **目次管理**: 記事一覧は [index.md](./index.md) で一元管理し、記事の追加・更新時に合わせて自動更新します。
