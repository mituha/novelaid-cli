# 第0回：はじめに —— AIエージェントで創る「小説執筆補助CLI」開発記、始動！

こんにちは！
本連載は、**AIエージェントを活用して小説執筆を補助するCLIツール（`novelaid-cli`）を開発するプロセスそのものを、AI自身の手によって記録・連載記事化していく実験的メイキングプロジェクト**です。

---

## 1. プロジェクトの目的：なぜ「小説執筆」×「CLIツール」なのか？

本プロジェクト「`novelaid-cli`」には、大きく分けて2つの目的（検証テーマ）があります。

### ① Pi Coding Agent SDK による小説執筆支援CLIの実現
小説の執筆作業は、単なる文章生成にとどまりません。世界観の整合性チェック、プロット・伏線管理、登場人物（キャラクター）設定の参照、シーンごとの推敲など、多岐にわたる複雑な情報管理が必要です。

本プロジェクトでは、自律型コーディングエージェント **[Pi Coding Agent](https://pi.dev/)** のSDK（[ドキュメント](https://pi.dev/docs/latest/sdk)）を採用し、開発者や執筆者がターミナル環境から軽快にAIと対話・執筆補助を受けられるCLIツールが作成可能かを検証します。

### ② 「開発ログの記録」と「メイキング記事」の完全自動化
開発と並行して、**「AIに作業ログを克明に記録させ、さらにそのログからnote等の連載記事を自動生成・更新させる」** というワークフロー自体の検証も行います。

この記事自体も、人間が入力したプロンプトをもとにAIエージェント（Antigravity）が推敲・執筆しています！

### 各フォルダーの役割と「コンテキスト分離の鉄則」

本プロジェクトで最もこだわっている設計思想の1つが、**「コンテキストの明確な分離」**です。

* **`.agents/`**：AIエージェントの頭脳・拡張機能
  * `hooks.json`：ユーザーのプロンプト入力やタスク完了を検知してスクリプトを自動発火させるライフサイクルフック。
  * `scripts/`：会話ログからプロンプトを正確に抽出し、ログへ自動同期するPowerShellスクリプトなど。
  * `skills/making-note-writer/`：ログと仕様書を読み解き、本記事のようなメイキング記事を自動執筆・更新するための専門スキル。
* **`docs/`**：プロダクト（`novelaid-cli`）の正式ドキュメント
  * `docs/dev/`：システム仕様書、設計メモ、アーキテクチャ計画書。
  * `docs/manual/`：将来的に一般公開するユーザー向け利用マニュアル。
* **`making/`**：開発プロセスの記録・連載記事
  * `making/logs/`：AIへの指示プロンプト原文と作業履歴の日次ログ。
  * `making/notes/`：本記事をはじめとする、note等外部公開用のメイキング連載記事。

> **💡 なぜコンテキストを分離するのか？**
> AIエージェントにプログラミングを任せると、作業ログや制作秘話、小説自体の設定資料、ツールの仕様書などが1つの文脈に混ざり合ってしまい、AIの注意（コンテキスト）が散漫になってしまう問題（コンテキスト汚染）が発生します。
> これを防ぐため、「システム仕様（docs）」「制作過程の記録（making）」「エージェント自身の拡張機能（.agents）」を物理的にもルール的にも厳格に分離しています。
