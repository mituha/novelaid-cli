# 第0回：はじめに

## 目的

このプロジェクトはAIエージェントを使って小説執筆補助用のCLIツールを作成するプロジェクトであり、同時にそのシステム構築経過自体も記録・記事化していくものです。
また、この記事自体もAIに書かせるものとします。

## 環境

* **Antigravity**
    + Antigravity（AIエージェント）
    + Antigravity IDE
* **Orca**
    + Orca ADE
* **git**（バージョン管理）
* Pi coding agent SDK

## 初期状態

### 各フォルダーの役割と意図

* **`.agents`**：AIエージェントに関する設定やスキルを格納するフォルダーです。
    + **`hooks.json`**：スクリプトのフックの設定を格納します。
    + **`scripts`**：AIが利用するスクリプトを格納します。
    + **`skills`**：AIエージェントが利用するスキルを格納します。
* **`docs`**：ドキュメントを格納するフォルダーです。
    + **`dev`**：開発仕様書、システム計画書、途中作業の設計メモなどを格納します。
    + **`manual`**：`novelaid-cli`のユーザー向けマニュアルを格納します。
* **`making`**：この実験プロジェクトの作業手順やログ、そして公開用の記事をまとめるフォルダーです。
  * **`making/logs`**：日々の作業内容や、AIに入力したプロンプトを記録します。
  * **`making/notes`**：noteなどに投稿するためのメイキング記事を格納します。
