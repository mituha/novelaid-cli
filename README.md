# novelaid-cli

小説執筆補助用のAIエージェント。

## このプロジェクトの目的

最終的には、小説執筆補助用のAIエージェントを作成するのが目的です。

ただし、プロジェクト自体がAIを利用したプログラミングやその過程の記録をかねています。  
今回は、

* Pi codeing agent を利用したCLIツールの作成が可能かの検証
* 作業内容の記録と記事の自動作成が可能かの検証

もプロジェクトの目的となっています。

## プログラミング環境

* Antigravity
* Orca

## Pi Coding Agent

* https://pi.dev/
* https://pi.dev/docs/latest
* https://pi.dev/docs/latest/sdk

このSDKを利用して、小説執筆の補助を行うCLIツールを作成します。

## 記事の自動作成

* AIによる作業ログの記録
* 作業ログからの記事の作成

これらを行うスキルを別途実験的に作成していたプロジェクトから持ってきました。
