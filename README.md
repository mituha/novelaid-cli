# novelaid-cli

[![npm version](https://badge.fury.io/js/novelaid-cli.svg)](https://www.npmjs.com/package/novelaid-cli)
[![Node.js Version](https://img.shields.io/node/v/novelaid-cli)](https://nodejs.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

**novelaid-cli** は、作家が作品の世界観・プロット・原稿の文脈を保ったまま、AIと二人三脚で執筆を進められるように設計された **小説執筆補助特化型の対話型AIエージェントCLI** です。

[Pi Coding Agent SDK](https://pi.dev/) の公式エコシステム上に構築され、美しいフルTUI画面、ローカルAI（LM Studio）との自動連携、そして深いフォルダー階層を自由に行き来できる安全な現在地管理（`/cd`, `/ls`, Tab補完）を備えています。

---

## 🌟 主な特徴

* 🖥️ **Pi SDK 公式フルTUI統合**
  * ストリーミング描画、リッチなMarkdown装飾、シンタックスハイライト、対話型コマンドパレットを標準装備。
* 🔒 **ローカルAI（LM Studio）自動連携**
  * プライバシーを重視し、手元のPC内で稼働する LM Studio サーバーを自動検知してプロバイダー登録。機密の原稿やアイデアを外部クラウドに送ることなく執筆相談が可能です。
* 📂 **境界保護付きフォルダー移動（`/cd`）と現在地管理（`/pwd`）**
  * 小説執筆特有の深い階層（設定、全体プロット、章ごとのプロット、各話原稿）を自在に移動。プロジェクトルートより外側への誤移動を防ぐ「ルート上限ガード」を搭載。
* 📋 **作業フォルダー内の一覧確認（`/ls` / `/dir`）**
  * 移動先の中身を即座に確認。隠しファイルを自動除外してフォルダーを優先表示し、ファイルサイズも人間が読みやすい形式に整形。
* ⚡ **Pi SDK 公式拡張APIによる動的 Tab 補完（Autocomplete）**
  * `/cd ` や `/ls ` の入力時に、現在地直下のフォルダー候補が自動ポップアップ。深い階層のフォルダー名も Tab キーで流れるように連続補完できます。

## 🚀 クイックスタート

### インストール不要で即時実行（npx）

Node.js がインストールされている環境であれば、事前のインストールなしで即座に実行できます。

```bash
npx novelaid-cli
```

### グローバルインストール

常用する場合は、グローバルインストールすることで `novelaid` コマンドとして起動できます。

```bash
# インストール
npm install -g novelaid-cli

# 起動（任意の小説フォルダーで実行）
novelaid
```

### プロジェクトフォルダーの指定

通常は起動したカレントディレクトリを作業対象としますが、引数で対象フォルダーを明示的に指定することも可能です。

```bash
# オプション指定
novelaid -p ./my-novel
novelaid --project "D:/novels/fantasy-epic"

# 位置引数での指定
novelaid ./my-novel
```

## ⌨️ 主なコマンド・操作一覧

TUIの入力欄から以下のスラッシュコマンドが利用可能です。

| コマンド | 説明 |
|---|---|
| `/pwd` | 現在の作業フォルダーの位置（相対パス・絶対パス・書庫ルート）を表示 |
| `/cd [パス]` | 作業フォルダーを移動（例: `/cd 10_novels`, `/cd ..`, 引数なしでルート復帰）。**Tabキーによるフォルダー補完対応** |
| `/ls [パス]` (または `/dir`) | 現在の作業フォルダー（または指定フォルダー）内のファイル・フォルダー一覧を表示 |
| `/model` | 利用可能なAIモデル（LM Studioや外部API）を対話リストから切り替え |
| `/novelaid-info` | novelaid-cli の接続状況・プラグイン情報・現在の作業フォルダーを表示 |
| `/help` | Pi SDK が提供する全コマンド一覧を表示 |
| `Ctrl+C` または `/exit` | セッションを終了 |

## 📋 動作要件

* **Node.js**: `v18.0.0` 以上
* **（推奨）LM Studio**: ローカルLLMで執筆を行う場合は、[LM Studio](https://lmstudio.ai/) を起動しローカルサーバーを有効化してください。
